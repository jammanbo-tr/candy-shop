# USB 시연 패키지 (usb-gpt)

이 폴더는 연구대회 시연을 위해 제작된 오프라인 웹앱 패키지입니다. `program/index.html` 파일을 실행하면 교사/학생 페이지를 선택할 수 있으며, 모든 컨텐츠는 네트워크 연결 및 계정 로그인 없이 동작하도록 구성되어 있습니다.

## 폴더 구성
- `document/` : 필수 제출 서류(연구보고서 hwp/pdf, 주요 화면 이미지)를 저장할 위치
- `media/` : 시연에 사용되는 이미지·동영상·오디오 리소스
- `program/` : 시연용 정적 웹앱 실행 파일 (`index.html`, `teacher.html`, `student.html`)
- `source/` : 필요 시 개발 소스 구조를 추가할 수 있는 공간 (현재는 안내 파일만 포함)

## 실행 방법
1. USB에서 `program/index.html`을 더블클릭하여 실행합니다.
2. 교사 또는 학생 화면을 선택해 즉시 시연을 진행합니다.
3. 시연 과정에서는 계정 로그인이나 비밀번호 입력이 필요 없습니다.

## 이미지 자원
시연 페이지에서 사용하는 모든 이미지는 `media/image` 경로와 연동되어 있으며, 필요 시 해당 폴더에 이미지를 추가/교체할 수 있습니다.
