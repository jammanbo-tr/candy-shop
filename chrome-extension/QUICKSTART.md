# 🚀 빠른 시작 가이드

## 1️⃣ Chrome에 확장 프로그램 설치

1. Chrome 브라우저에서 `chrome://extensions/` 접속
2. 우측 상단의 **개발자 모드** 토글 활성화
3. **압축해제된 확장 프로그램을 로드합니다** 버튼 클릭
4. `candy-shop/chrome-extension` 폴더 선택
5. 확장 프로그램이 설치되면 툴바에 아이콘이 나타남

## 2️⃣ Firebase 설정 (처음 한 번만)

### Firebase 프로젝트가 이미 있다면:

1. 확장 프로그램 아이콘 클릭
2. **옵션 열기** 버튼 클릭
3. Firebase 설정 JSON 붙여넣기:

```json
{
  "apiKey": "AIza...",
  "authDomain": "candy-shop-8394b.firebaseapp.com",
  "projectId": "candy-shop-8394b",
  "storageBucket": "candy-shop-8394b.appspot.com",
  "messagingSenderId": "...",
  "appId": "..."
}
```

4. **설정 저장** 클릭

### Firebase 프로젝트가 없다면:

1. [Firebase Console](https://console.firebase.google.com/) 접속
2. **프로젝트 추가** 클릭
3. 프로젝트 이름 입력 (예: `candy-classroom`)
4. Firestore Database 생성:
   - 좌측 메뉴 > **Firestore Database** 클릭
   - **데이터베이스 만들기** → 테스트 모드로 시작
5. Authentication 활성화:
   - 좌측 메뉴 > **Authentication** 클릭
   - **시작하기** → **이메일/비밀번호** 활성화
6. 프로젝트 설정에서 Firebase config 복사

## 3️⃣ 첫 사용자 등록 (관리자)

1. 확장 프로그램 아이콘 클릭
2. **관리자 가입** 탭 선택
3. 정보 입력:
   - 관리자 표시 이름: `홍길동`
   - 이메일: `admin@example.com`
   - 비밀번호: `password123` (8자 이상)
4. **관리자 계정 생성** 클릭
5. 자동 로그인됨

## 4️⃣ 교사 초대하기

### 관리자로서:
1. 로그인 후 "교사 초대코드 발급" 버튼 클릭
2. 메모 입력 (선택): `1학년 담임`
3. 생성된 코드 확인 (예: `교사_행복한강아지_X9K`)
4. 이 코드를 교사에게 전달

### 교사 가입:
1. 새 Chrome 프로필 또는 시크릿 모드 사용
2. 확장 프로그램 > **교사 가입** 탭
3. 정보 입력 및 **관리자 초대코드** 입력
4. 계정 생성

## 5️⃣ 학생 초대하기

### 교사로서:
1. 로그인 후 "학생 초대코드 발급" 버튼 클릭
2. 생성된 코드 확인 (예: `학생_빨간고양이_B7X`)
3. 학생들에게 코드 공유

### 학생 가입:
1. **학생 가입** 탭에서 회원가입
2. **교사 초대코드** 입력
3. 계정 생성

## 6️⃣ 수업 시작하기

### 교사:
1. 확장 프로그램 팝업에서 **클래스 시작** 버튼 클릭
2. 브라우저 우측의 **사이드바 열기** (또는 확장 프로그램 아이콘 우클릭)
3. 사이드바에서:
   - 접속한 학생 목록 확인
   - 실시간 채팅 가능
   - 링크 공유 (학생들에게 자동 전달)

### 학생:
1. 로그인만 하면 대기 상태
2. 선생님이 수업 시작하면 사이드바 자동 활성화
3. 사이드바에서:
   - 실시간 채팅 참여
   - 선생님이 공유한 링크 확인 및 클릭

## 7️⃣ 수업 종료하기

교사가 **클래스 종료** 버튼 클릭하면:
- 채팅 비활성화
- 자동으로 다음 수업용 학생 초대 코드 생성됨
- 학생들의 사이드바는 대기 모드로 전환

## 🎯 테스트 시나리오

### 완전한 테스트를 위한 3개 Chrome 프로필 사용:

**프로필 1: 관리자**
```
이메일: admin@test.com
비밀번호: admin123!
```

**프로필 2: 교사**
```
이메일: teacher@test.com
비밀번호: teacher123!
초대코드: (관리자가 생성한 코드)
```

**프로필 3: 학생**
```
이메일: student@test.com
비밀번호: student123!
초대코드: (교사가 생성한 코드)
```

### 테스트 순서:
1. 프로필 1에서 관리자 가입 → 교사 초대 코드 생성
2. 프로필 2에서 교사 가입 → 학생 초대 코드 생성
3. 프로필 3에서 학생 가입
4. 프로필 2에서 수업 시작
5. 프로필 3 사이드바에서 채팅 활성화 확인
6. 프로필 2에서 메시지 및 링크 공유
7. 프로필 3에서 수신 확인
8. 프로필 2에서 수업 종료
9. 새 초대 코드 자동 생성 확인

## 🐛 문제 해결

### "Firebase 설정이 필요합니다" 오류
→ 옵션 페이지에서 Firebase 설정 저장 확인

### 사이드바가 안 보임
→ 확장 프로그램 아이콘 우클릭 → "사이드바 열기"

### 채팅이 활성화 안 됨
→ 교사가 "클래스 시작"을 눌렀는지 확인

### 초대 코드 오류
→ 코드를 정확히 복사했는지 확인 (대소문자 구분)

## 📱 사이드바 열기 방법

1. **방법 1**: 확장 프로그램 아이콘 우클릭 → "사이드바 열기"
2. **방법 2**: Chrome 설정 → 사이드바 → Classroom Relay 선택
3. **방법 3**: 단축키 설정 가능 (`chrome://extensions/shortcuts`)
